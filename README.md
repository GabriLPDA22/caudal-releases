# Caudal · descargas

APK de Caudal para Android. Este repo solo contiene las versiones publicadas (sin código).

## Instalar o actualizar

1. Abre la última versión en [Releases](https://github.com/GabriLPDA22/caudal-releases/releases/latest) y descarga `Caudal-X.Y.Z.apk`.
2. Ábrelo en el móvil y acepta la instalación.

Si ya tienes Caudal, instálalo **encima**: no se pierde nada. Android solo acepta la actualización si está firmada con la misma clave que la versión instalada.

Para comprobar la descarga, cada versión incluye su `.sha256`.

La app avisa sola cuando hay una versión nueva (Ajustes → Buscar versiones nuevas).
